Première version publiée de **Gná**, bastion d'accès SSH, VNC et RDP.

## Installation

**Serveur** (Debian 12+ / Ubuntu 22.04+) :
```bash
sudo apt install ./gna-server_0.13.0_amd64.deb
```
PostgreSQL, le service systemd et la configuration sont créés automatiquement. Puis créer le premier administrateur : `sudo -u gna gna user add admin --admin`, et ouvrir `https://<ip-du-serveur>:8443`.

**Applications** — à la première ouverture, saisir l'adresse du serveur puis comparer l'empreinte affichée avec `sudo -u gna gna tls info` sur le serveur :

| Système | Fichier | Installation |
|---|---|---|
| Linux (Debian, Ubuntu) | `gna-app_0.13.0_amd64.deb` | `sudo apt install ./gna-app_0.13.0_amd64.deb` |
| Linux (autres) | `Gna-0.13.0-x86_64.AppImage` | `chmod +x Gna-*.AppImage` puis l'ouvrir |
| Windows 10/11 | `Gna-0.13.0-windows-setup.exe` | Lancer l'installeur (non signé : « Informations complémentaires » → « Exécuter quand même ») |
| Android 7+ | `Gna-0.13.0-android.apk` | Ouvrir le fichier sur le téléphone et autoriser l'installation d'applications inconnues |

Empreintes SHA-256 : `SHA256SUMS.txt`.

## Contenu

- SSH, VNC et RDP dans le navigateur ou l'application ; fichiers SFTP et transferts RDP
- Mot de passe + MFA, droits par utilisateur et par groupe, journal d'audit, enregistrement des sessions
- Onglets, mosaïque, saisie synchronisée, bibliothèque de commandes, espaces de travail, favoris et dossiers
- Copier-coller direct, redimensionnement automatique, touches spéciales
- 7 thèmes (Sombre, Clair, Nord, Dracula, Gruvbox, Solarized, Système)
