## Correction

- Le serveur 0.14.0 publié ici ne démarrait pas sur certains systèmes (service tué au démarrage, `signal=SYS`) : la protection systemd du service refusait un appel système fait par Go au lancement. Un appel interdit est désormais refusé proprement au lieu d'arrêter le service, et le serveur est compilé avec la même version de Go que les versions testées.

Contient aussi les nouveautés de la 0.14.0 (verrouillage après inactivité, mot de passe seul pendant 4 h).

```bash
sudo apt install ./gna-server_0.14.1_amd64.deb
```
