## Nouveautés

- **Verrouillage après inactivité au lieu d'une déconnexion** : après 30 min sans activité, la session est verrouillée et le **mot de passe seul** suffit pour reprendre, tant que le dernier code TOTP date de moins de 4 h. Au-delà, connexion complète avec code TOTP.
- **Correction** : quand la session se fermait côté serveur, l'interface restait affichée comme connectée sans pouvoir ouvrir de machine. Elle vérifie maintenant la session toutes les 30 s et affiche aussitôt l'écran de verrouillage ou de connexion.
- Seule l'activité réelle (clavier, souris, toucher) repousse le verrouillage.

**Correctif (12/10)** : le premier paquet serveur de cette version ne démarrait pas sur certains systèmes (service arrêté au lancement, `signal=SYS`). Les fichiers ont été remplacés : la protection systemd refuse désormais proprement un appel interdit au lieu d'arrêter le service. Si vous aviez installé le premier paquet, réinstallez celui-ci.

Réglages (dans `/etc/gna/gna.env`) : `GNA_IDLE_TIMEOUT` (30m), `GNA_MFA_REMEMBER` (4h, `off` pour exiger le code à chaque fois).

## Mise à jour du serveur

```bash
sudo apt install ./gna-server_0.14.0_amd64.deb
```
Les applications n'ont pas besoin d'être réinstallées : l'interface vient du serveur.
