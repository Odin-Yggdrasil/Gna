# Logo Gná

Même style que les bindrunes de Saga et d'Andvari : grille 64×64, traits de 5, angles vifs,
tuile arrondie (rx 12).

**Bindrune** : les trois runes du nom fusionnées en un seul signe — ᚷ Gebo (G, le don,
l'échange), ᚾ Naudiz (N, la nécessité) et ᚨ Ansuz (A, les dieux, le message : Gná est la
messagère de Frigg). L'anneau de runes (`server/internal/web/static/anneau-runes.svg`) se lit
« GNA · HOFVARPNIR · FRIGG · ASGARD » en vieux futhark.

| Couleur         | Valeur    | Usage                               |
|-----------------|-----------|-------------------------------------|
| Bleu-vert       | `#5FB3A1` | Accent thème sombre                 |
| Bleu-vert foncé | `#2F8F7B` | Accent thème clair (glyphe blanc)   |
| Nuit            | `#0E1116` | Glyphe / fond sombre                |

Famille : Gná `#5FB3A1` (bleu-vert), Andvari `#E0B04A` (or), Saga `#9B8AFB` (améthyste).

## Fichiers

- `bindrune/gna-icone-*.svg` : tuile (sombre, clair, noir, blanc, contour) et glyphe seul.
- `bindrune/gna-logo-*.svg` : tuile + nom.
- `bindrune/favicon.svg` (trait de 6 pour la lisibilité), `favicon.ico`, `gna-{32,180,512}.png`.
- `variantes/` : pistes écartées (Ansuz seule, bastion, aile, monogramme, Hófvarpnir).

Aperçu : `apercu-bindrune.png`.
