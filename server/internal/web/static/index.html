    Compte

    Double authentification

    active Obligatoire sur Gná : un code de votre application est demandé à chaque connexion. Téléphone perdu : un administrateur peut la réinitialiser.

    Mot de passe

    Vos sessions sur les autres appareils sont fermées. Mot de passe perdu : sudo -u gna gna user passwd <nom> sur le serveur.

    Apparence

    Thèmes communs à Gná, Saga et Andvari. Appliqué tout de suite, aux terminaux et aux bureaux compris ; enregistré pour votre compte (navigateur et application).

    Commandes

    Votre bibliothèque de commandes, envoyées d'un clic dans le terminal actif (ou dans tous les terminaux synchronisés) depuis le menu « Commandes » des sessions SSH.

    Jetons d'accès

    Pour un script ou un menu du bureau : lecture seule de la liste de vos machines (GET /api/targets), avec l'en-tête Authorization: Bearer …. Un jeton n'ouvre aucune session et ne permet aucune modification. Il n'est affiché qu'une fois : rangez-le dans votre gestionnaire de secrets.

    Utilisateurs

    Utilisateur : accède aux machines qui lui sont attribuées (directement ou par un groupe). Administrateur : toutes les machines, l'administration, les sessions et le journal.

    Groupes

    Un groupe attribue des machines à plusieurs utilisateurs d'un coup.

    Liaisons

    Les autres outils de la famille Runa peuvent ajouter des machines à Gná : Völund envoie chaque machine qu'il installe, avec sa clé d'hôte SSH lue pendant l'installation. Une liaison ne voit aucun identifiant de connexion et ne supprime rien ; les machines ajoutées restent à compléter. Andvari peut ensuite envoyer, chiffré pour Gná seul, le mot de passe d'une machine : il devient son mot de passe sudo (bouton dans le terminal), et ses identifiants si elle était à compléter.

          Comparez l'empreinte avec celle du serveur : ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
